# averis
Averis Hackathon 2026



## Setup instruction



### Step 1: Clone the Repository
```bash
git clone
https://github.com/WanQi-01/averis.git
```

### Step 2: Navigate into project folder
```bash
cd averis
```

### Step 3: Install Dependencies
Navigate into the app folder and install dependencies:
```bash
cd averisapp
npm install
```
